================================================================================
ARREGLO OBLIGATORIO EN EL VPS (no se soluciona desde el navegador ni GitHub)
================================================================================

Diagnóstico actual (julio 2026):
  curl -sI https://erpmaster.cl/riomaipo/
  → HTTP 302
  → Location: https://erpmaster.cl/laconcepcion/

Por eso Chrome (aunque borres datos) siempre cae en La Concepción:
nginx redirige /riomaipo al ERP La Concepción. Hay que cambiar nginx EN EL SERVIDOR.

--------------------------------------------------------------------------------
OPCIÓN RÁPIDA (recomendado) — en SSH del VPS:
--------------------------------------------------------------------------------

  cd /var/www/erpmaster/constructpro-erp    # o la carpeta real del repo
  git pull origin cursor/riomaipo-track-abb4
  sudo bash scripts/install_riomaipo_vps.sh

--------------------------------------------------------------------------------
OPCIÓN MANUAL (si no usas el script):
--------------------------------------------------------------------------------

1) Arrancar Río Maipo en puerto 8503 (NO el de La Concepción):

  cd /ruta/del/repo
  python3 -m venv .venv && source .venv/bin/activate
  pip install -r requirements.txt
  streamlit run app_riomaipo.py \
    --server.address 127.0.0.1 \
    --server.port 8503 \
    --server.baseUrlPath riomaipo \
    --server.headless true

2) Editar el vhost de nginx de erpmaster.cl, por ejemplo:

  sudo nano /etc/nginx/sites-available/erpmaster.cl

3) PEGAR ESTE BLOQUE ANTES de cualquier línea que diga laconcepcion
   (si lo pegas después, seguirá cayendo en La Concepción):

  location = /riomaipo { return 301 /riomaipo/; }
  location /riomaipo/ {
      proxy_pass http://127.0.0.1:8503/riomaipo/;
      proxy_http_version 1.1;
      proxy_set_header Host $host;
      proxy_set_header Upgrade $http_upgrade;
      proxy_set_header Connection "upgrade";
      proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
      proxy_set_header X-Forwarded-Proto $scheme;
      proxy_read_timeout 86400;
      proxy_buffering off;
  }

4) Probar y recargar:

  sudo nginx -t && sudo systemctl reload nginx

5) Verificar (debe ser 200, NO 302 a laconcepcion):

  curl -sI https://erpmaster.cl/riomaipo/

--------------------------------------------------------------------------------
Puertos (no mezclar)
--------------------------------------------------------------------------------
  /laconcepcion  → Streamlit La Concepción  (ej. 8501)
  /demo          → Streamlit Demo           (ej. 8502)
  /riomaipo      → Streamlit Río Maipo      (8503)

Si /riomaipo apunta al puerto de La Concepción, verás La Concepción.
